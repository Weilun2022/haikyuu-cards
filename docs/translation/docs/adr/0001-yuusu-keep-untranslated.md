# P03 系列「ユース」「疑似ユース」保留日文原文，不翻譯

`translate_skill()` 的規則明確跳過這兩個詞，讓它們原封不動出現在 `skill_zh` 裡（其餘同段落文字正常翻譯）。

## Considered Options

- 翻成「全日本青年」「青年隊」「全日青」等中文詞——討論後認為每個選項都有明顯缺點（過長、跟其他既有術語混淆、或不夠精確對應原意）。
- **保留日文原文（現行）**：不完美但比任何一個中文選項的缺點都小，六方協作討論後由使用者定案。

## Consequences

假名殘留掃描腳本（含 `check_translations.js`）都必須把這兩個詞排除在「疑似漏翻」的偵測範圍外，不然每次掃描都會誤報。之後如果有更好的中文譯法出現，要重新翻譯的話得同步更新掃描腳本的排除清單，不能只改 `translate_skill()`。
