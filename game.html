🔥 設定 Firebase 連線

首次使用需輸入你的 Firebase 設定。完成後會儲存在瀏覽器，之後不需重複。

1. 前往 console.firebase.google.com 建立新專案
2. 專案 → 新增應用程式 → 網頁 → 取得 firebaseConfig
3. 左側選單 → Realtime Database → 建立資料庫（選測試模式）
4. 將 firebaseConfig 物件的 JSON 貼入下方

🏐 バボカ!! BREAK — 遊戲說明
了解流程與操作後即可開始對戰
1
🎲
先攻後攻決定
點右側「先攻後攻」按鈕擲骰子。選單/雙，贏的人選擇先攻或後攻。
2
🃏
雙方各抽牌至 6 張手牌
按 D 鍵或點牌庫格子抽牌，抽到手牌剛好 6 張。
3
🤝
與對手討論要放回幾張
雙方公開討論（語音或文字），決定各自要放回牌庫的張數。
4
↩
將決定的牌放回牌庫
右鍵手牌 → 放回牌庫頂／底；或點擊手牌進入選牌模式後，點牌組格子上半（牌頂）/ 下半（牌底）放回。
5
🔀
雙方各自洗牌
點右側「🔀 洗牌」按鈕，將牌庫順序隨機洗亂。
6
🃏
再次抽牌至 6 張手牌
同步驟 2，將手牌補回 6 張。
7
🏆
先攻方補充 SET 池，開始第一回合
先攻方點場地左側 SET 數字，從牌庫頂取 2 張到 SET 池。然後由先攻方開始行動。
場地區域
🏐 發球區用發球值作為本回合攻擊值（先攻）
🤝 接球區接球值 ≥ 對手攻擊值時防守成功，攻擊警示解除
🟢 舉球區舉球值＋攻擊區攻擊值 = 本方攻擊力
⚡ 攻擊區攻擊值，與舉球合計作為本方攻擊力
🛡️ 攔網區總攔網值 ≥ 對手攻擊值時攔網成功，攻擊警示解除
📋 事件區效果牌放置處，可疊放多張
手牌操作
點擊手牌進入選牌模式，高亮可放置區域，再點場地格子放置
右鍵手牌快速選單：移至場上 / 放回牌庫頂或底 / 棄牌
多選放回選牌模式下繼續點其他手牌可累加選取，一次放回多張到牌庫
拖曳手牌直接拖到場地格子放置，拖到牌庫格子放回（上半=頂/下半=底）
SET 池 ＆ 輸球
補充 SET點場地左側 SET 數字，從牌庫頂取 2 張進入 SET 池
輸一球點「輸一球」：先從牌庫補手牌到 6 張，再從 SET 池取 1 張加入手牌，自動結束回合
其他操作
復原每回合最多復原 10 步，結束回合後清除
棄牌區點棄牌格子查看；可從中撿回任一張到手牌
Guts 疊牌點場上角色右鍵 → Guts，或拖曳手牌到有角色的格子
攻擊警示對手結束回合時，其攻擊力閃爍顯示於對方場地；接球或攔網值達標後自動消失

Enter 結束回合
Esc 取消 / 關閉
