## 5. 遊戲進行（階段別）

### 通用骨架（各階段共通，下面不再重複說明）
- 「開始時」：此階段期間／該回合期間有效的效果生效；以「階段開始時」「回合開始時」為誘發條件的技能進入待機。接著執行檢查程序。
- 「結束時」：以「階段結束時」為誘發條件的技能進入待機 → 檢查程序 → 以「階段中」「此階段中」為期限的效果失效 → 進入下一階段。
- 「登場步驟」(5-13)：回合玩家若無法登場角色卡，必須宣告「失分（ロスト）」，進入失分重置步驟（5-20）。
- 「自由步驟」(5-14)：回合玩家若宣告失分，進入失分重置步驟（5-20）。

### 5-5. サーブフェイズ（發球階段）
- 5-5-1. 進行發球、開始一次來回（ラリー）的階段。
- 5-5-2. 步驟順序：
  1. 階段開始（見通用骨架；「サーブフェイズ中」「自己的回合中」「此一局中」為期限的效果生效）。
  2. 登場步驟（5-13）：若回合玩家無法登場角色卡 → 宣告失分 → 失分重置步驟（5-20）。每個步驟後都做檢查程序。
  3. 自由步驟（5-14）：回合玩家若宣告失分 → 失分重置步驟（5-20）。
  4. 進攻點數計算步驟（オフェンスポイント算出，5-17）。
  5. 階段結束（「サーブフェイズ終了時」誘發 → 檢查程序 → 期限效果失效）→ 進入**結束階段**（5-12）。
- 備註：發球階段沒有防守點數計算，也沒有判定步驟。

### 5-6. スタートフェイズ（回合開始階段）
- 5-6-1. 回合玩家執行自己回合開始時各種處理的階段。
- 5-6-2. 步驟順序：
  1. 階段開始（「スタートフェイズ中」「自己的回合中」為期限的效果生效；「階段開始時」「回合開始時」誘發技能待機；檢查程序）。
  2. **選擇攔網或接球**：回合玩家這個回合要進行攔網階段還是接球階段，在此選擇並宣告。
  3. 階段結束（「スタートフェイズ終了時」誘發 → 檢查程序 → 該階段期限效果失效）。
  - 分流：②選攔網 → 進入**ブロックフェイズ**（5-7）；②選接球 → 進入**ドローフェイズ**（5-8）。

### 5-7. ブロックフェイズ（攔網階段）
- 5-7-1. 回合玩家進行攔網的階段。
- 5-7-2. 步驟順序：
  1. 階段開始（「ブロックフェイズ中」期限效果生效；「階段開始時」誘發技能待機；檢查程序）。
  2. 登場步驟（5-13）：無法登場角色卡 → 宣告失分 → 失分重置步驟（5-20）。
  3. 自由步驟（5-14）：宣告失分 → 失分重置步驟（5-20）。
  4. **防守點數計算步驟**（ディフェンスポイント算出，5-18）。
  5. **判定步驟（ジャッジステップ）**：攔網失敗時，回合玩家必須宣告失分 → 失分重置步驟（5-20）。
     - 附圖補充：自己的防守點數**大於等於**對手攻擊的進攻點數＝攔網成功；否則攔網失敗，自動失分。
  6. 進攻點數計算步驟（5-17）。
  7. 階段結束：先把**所有「側攔網者」角色移到棄牌區（ドロップエリア）**；再「ブロックフェイズ終了時」誘發 → 檢查程序 → 期限效果失效 → 進入**結束階段**（5-12）。
- 攔網成功後：不失分，繼續算進攻點數，側攔網者清場，然後結束回合。攔網失敗後：在判定步驟當場失分，不會走到 ⑥。

### 5-8. ドローフェイズ（抽牌階段）
- 5-8-1. 從牌組把卡加入手牌的階段。
- 5-8-2. 步驟順序：
  1. 階段開始（「ドローフェイズ中」期限效果生效；「階段開始時」誘發技能待機；檢查程序）。
  2. 抽牌步驟（5-16）：回合玩家從牌組抽 **1 張**到手牌（附圖記載）。
  3. 自由步驟（5-14）：宣告失分 → 失分重置步驟（5-20）。
  4. 階段結束（「ドローフェイズ終了時」誘發 → 檢查程序 → 期限效果失效）→ 進入**接球階段**（5-9）。
- 備註：只有走「選擇接球」這條路才會抽牌；選攔網時整個回合跳過抽牌。此階段沒有登場步驟。

### 5-9. レシーブフェイズ（接球階段）
- 5-9-1. 回合玩家進行接球的階段。
- 5-9-2. 步驟順序：
  1. 階段開始（「レシーブフェイズ中」期限效果生效；「階段開始時」誘發技能待機；檢查程序）。
  2. 登場步驟（5-13）：無法登場角色卡 → 宣告失分 → 失分重置步驟（5-20）。
  3. 自由步驟（5-14）：宣告失分 → 失分重置步驟（5-20）。
  4. 防守點數計算步驟（5-18）。
  5. **判定步驟**：接球失敗時，回合玩家宣告失分 → 失分重置步驟（5-20）。
  6. 階段結束（「レシーブフェイズ終了時」誘發 → 檢查程序 → 「接球階段中」「此階段中」期限效果失效）→ 進入**トスフェイズ**（5-10）。
- 備註：接球階段沒有進攻點數計算；成功後直接接到托球。

### 5-10. トスフェイズ（托球階段）
- 5-10-1. 回合玩家進行托球的階段。
- 5-10-2. 步驟順序：
  1. 階段開始（「トスフェイズ中」期限效果生效；「階段開始時」誘發技能待機；檢查程序）。
  2. 登場步驟（5-13）：無法登場角色卡 → 宣告失分 → 失分重置步驟（5-20）。
  3. 自由步驟（5-14）：宣告失分 → 失分重置步驟（5-20）。
  4. 階段結束（「トスフェイズ終了時」誘發 → 檢查程序 → 期限效果失效）→ 進入**アタックフェイズ**（5-11）。
- 備註：托球階段既沒有防守點數／進攻點數計算，也沒有判定步驟。

### 5-11. アタックフェイズ（攻擊階段）
- 5-11-1. 回合玩家進行攻擊的階段。
- 5-11-2. 步驟順序：
  1. 階段開始（「アタックフェイズ中」期限效果生效；「階段開始時」誘發技能待機；檢查程序）。
  2. 登場步驟（5-13）：無法登場角色卡 → 宣告失分 → 失分重置步驟（5-20）。
  3. 自由步驟（5-14）：宣告失分 → 失分重置步驟（5-20）。
  4. 進攻點數計算步驟（5-17）。
  5. 階段結束（「アタックフェイズ終了時」誘發 → 檢查程序 → 「攻擊階段中」「此階段中」期限效果失效）→ 進入**エンドフェイズ**（5-12）。

### 5-12. エンドフェイズ（結束階段）
- 5-12-1. 在回合最後執行各種處理的階段。
- 5-12-2. 步驟順序：
  1. 階段開始：
     - 「エンドフェイズ中」為期限的效果生效；但**已經有效的技能不會重複生效**。
     - 以「エンドフェイズ開始時」「回合結束時」為誘發條件的技能進入待機；但**本回合已經待機過一次的技能不會再度待機**。
     - 執行檢查程序。
     - 若場上仍有以「回合結束時」為誘發條件、且本回合**還沒待機過**的技能，則**重複本步驟 ①**（階段開始的整套處理）；沒有了才進入 ②。
  2. 清理步驟（クリーンナップステップ，5-19）：持續效果結束；數值修正效果與固定效果結束（依附圖）。
  3. 階段結束：執行檢查程序；**結束這個回合**，把目前的非回合玩家換成回合玩家，進入下個回合的**スタートフェイズ**（5-6）。

## 9. キーワード（關鍵字）

### 9-1. キーワードの基準
- 9-1-1. 關鍵字是把特定的長指示或複合效果簡略成一個記號所寫成的技能。
- 9-1-2. 在本規則各項目中被定義為「關鍵字」的技能，才算關鍵字。

### 9-2. ドシャット N
- 9-2-1. 攔網成功時，會妨礙**下一個對手回合**中對手接球成功的**延遲型效果**。
- 9-2-2. 以「ドシャット N」圖示表示。
- 9-2-3. 以「進行攔網的那個回合的回合結束時」為誘發條件。
- 9-2-4. 此技能解決時，發生的指示：該回合結束時，**自己的進攻點數變為 N**。

### 9-3. ワンタッチ N
- 9-3-1. 靠攔網削弱對手來襲的攻擊、讓自己的接球更容易成功的**即時效果**。
- 9-3-2. 以「ワンタッチ N」圖示表示。
- 9-3-3. 此技能解決時，發生的指示：
  - 對手攻擊的進攻點數 **−N**。
  - **直接跳過進行中的攔網階段**，轉到自己的**ドローフェイズ**。
- 白話：攔網成功並削弱對手攻擊後，不做後續攔網階段步驟，直接抽牌接球。

### 9-4. フェイント N
- 9-4-1. 妨礙**下一個對手回合**中對手攔網成功的**延遲型效果**。
- 9-4-2. 以「フェイント N」圖示表示。
- 9-4-3. 以「進行攻擊的那個回合的回合結束時」為誘發條件。
- 9-4-4. 此技能解決時，發生的指示：
  - 該回合結束時，**自己的進攻點數變為 N**。
  - **下一個對手回合中，對手不能登場攔網角色**。

### 9-5. ブロックアウト N
- 9-5-1. 妨礙**下一個對手回合**中對手攔網成功的**延遲型效果**。
- 9-5-2. 以「ブロックアウト N」圖示表示。
- 9-5-3. 誘發條件：進行攻擊那個回合的**下一個對手回合**中，對手登場了「**原本的攔網點數（ブロックポイント）為 N 以下**」的攔網角色時。
- 9-5-4. 此技能解決時，發生的指示：**對手失分（ロスト）**（參照 1-4-9）。
- 白話：只有對手登場的攔網角色其卡面攔網點數 ≤ N 時才會發動，是直接逼對手失分。

### 9-6. ターン1
- 9-6-1. 限制同一個回合中，指定卡片的技能能使用幾次的**持續效果**。
  - 被指定的卡片＝以使用該技能的玩家為主人、且與寫有此技能的卡**同卡名**的卡。
- 9-6-2. 以「ターン1」圖示表示。
- 9-6-3. 當宣告使用了含有此技能的技能（下稱技能 A）時，依下列規則解決：
  - 技能 A 的效果即使只解決了一部分，此技能也必須解決。
  - 此技能在解決技能 A 時，**最後**才解決。
- 9-6-4. 此技能解決時，發生的指示：在該回合中，**使與寫有此技能那張卡同卡名的己方卡之技能無效化**（參照 6-1-2「無效技能」）。
- 白話：一回合內，同卡名的卡只能發動一次該技能。

### 9-7. Aパス N（黃底標示，疑為新增）
- 9-7-1. 托球角色（トスキャラ）登場時，強化該角色的**托球點數（トスポイント）**的**即時效果**。
  - 註：トスキャラ＝托球角色。
- 9-7-2. 以「Aパス N」圖示表示（PDF 圖示為空白，無法確認圖示樣式）。
- 9-7-3. 誘發條件：**該回合中，托球角色登場時**。
- 9-7-4. 此技能解決時，發生的指示：**登場的托球角色的托球點數 +N**。

### 9-8. ツーアタック N（黃底標示，疑為新增）
- 9-8-1. 以托球把球回到對手場地、閃避對手攔網的**即時效果與持續效果**。
- 9-8-2. 以「ツーアタック N」圖示表示（PDF 圖示為空白）。
- 9-8-3. 此技能解決時，發生的指示：
  - 算出**自己攻擊的進攻點數**，並把該進攻點數**變為 N**。
  - **直接跳過進行中的托球階段**，轉到自己的**エンドフェイズ**。
  - **下一個對手回合中，對手不能登場攔網角色**。
- 白話：托球階段就直接打過去，不經過攻擊階段，進攻點數固定為 N，並且阻止對手下回合攔網。

### 第 9 章對照速查
| 關鍵字 | 類型 | 誘發 | 效果摘要 |
|---|---|---|---|
| ドシャット N | 延遲型 | 攔網回合的回合結束時 | 回合結束時，自己的進攻點數＝N（影響對手下回合接球） |
| ワンタッチ N | 即時 | （解決時） | 對手攻擊進攻點數 −N；跳過進行中的攔網階段，換自己抽牌階段 |
| フェイント N | 延遲型 | 攻擊回合的回合結束時 | 進攻點數＝N；對手下回合不能登場攔網角色 |
| ブロックアウト N | 延遲型 | 對手下回合登場「攔網點數 ≤ N」的攔網角色 | 對手失分 |
| ターン1 | 持續 | — | 同回合內同卡名的卡只能用一次該技能 |
| Aパス N | 即時 | 該回合中托球角色登場時 | 登場的托球角色托球點數 +N |
| ツーアタック N | 即時＋持續 | — | 進攻點數＝N；跳過托球階段到結束階段；對手下回合不能登場攔網 |
