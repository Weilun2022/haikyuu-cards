## 【restore_event_names 修改後完整程式碼】

```python
def restore_event_names(text: str, zh_to_jp: dict) -> str:
    """將 Q&A 文字中已翻譯的中文事件牌名還原為日文原文。"""
    if not text:
        return text
    for zh, jp in zh_to_jp.items():
        text = text.replace(zh, jp)
    for zh, jp in QA_EVENT_ZH_MAP.items():  # 補救層：修正 AI 與 translate_skill 翻譯不一致的情況
        text = text.replace(zh, jp)
    return text
```

## 【說明】

### 問題根源

`restore_event_names()` 使用 `zh_to_jp_event` 反查表，其鍵值是由 `translate_skill(jp_name, event_names=[])` 計算出的中文譯名。但 `translate_skill` 的翻譯規則不完整，對部分事件牌名產生：

1. **日中混雜**：如 `誰だろうと受けて立つ` → `誰だろう和受けて立つ`（`と` 被誤翻為 `和`）
2. **未翻譯**：如 `ブロード攻撃`、`清水 潔子`、`大見 太郎`、`黒須 法宗`、`追分 拓朗` 保持日文不變

而 `qa_data_zh.json` 是由 AI（Google Translate 或 GPT）翻譯的，AI 針對這些牌名使用了完全不同的中文翻譯。結果 `zh_to_jp_event` 的鍵不存在於 `qa_data_zh.json` 的文字中，造成還原失敗。

### 修復策略

新增 `QA_EVENT_ZH_MAP` 常數，直接儲存「AI 實際翻譯結果 → 日文牌名」的對照表。`restore_event_names()` 在跑完原有 `zh_to_jp_event` 替換後，再跑一次 `QA_EVENT_ZH_MAP` 替換作為補救層。

### 子字串衝突處理

`今天要做什麼` 是 `你今天要做什麼？` 的子字串，若先替換短串會污染長串。`QA_EVENT_ZH_MAP` 中已確保 `你今天要做什麼？` 排在 `今天要做什麼` 之前（Python 3.7+ 保證 dict 插入順序），`str.replace` 依序執行，可正確處理。

### 特殊案例

- **`超\u200b\u200b級內心十字!!!`**：AI 翻譯 `超インナークロス!!!` 時在「超」和「級」之間插入了兩個 U+200B 零寬空格，需額外處理此變體。
- **`音駒の専売特許じゃねえぞォ！`**：Q&A 的日文原文使用 `じゃねぇぞ`（小字 ぇ），與 `all_cards.json` 牌名 `じゃねえぞ` 不同，導致原本的 marker 掃描無法偵測到此卡的 Q&A 條目。`QA_EVENT_ZH_MAP` 補救層仍能還原 zh 文字中的中文譯名。
- **`がんばれ`**：AI 以羅馬字 `Ganbare` 翻譯，translate_skill 給出 `んばれ`（首字被截），兩者均無法匹配，需同時在 `QA_EVENT_ZH_MAP` 補 `Ganbare`。
- **`どん ぴしゃり`**：AI 在不同 Q&A 使用 `Don Slap` 與 `Don Smack` 兩種不一致的翻譯，均需補入。

## 【遺留問題】

1. **`音駒の専売特許じゃねえぞォ！` 的 JP 文字差異**：Q&A 日文中使用 `じゃねぇぞ`（小字ぇ），牌名為 `じゃねえぞ`（大字え），這是資料來源本身的不一致（非此次任務範圍），建議中樞記錄備查。

2. **`超インナークロス!!!` 的 zero-width space 問題**：`qa_data_zh.json` 中 HV-P02-007/351A 的翻譯文字含 U+200B，是 AI 翻譯時引入的隱藏字元。`QA_EVENT_ZH_MAP` 已納入此特殊字元版本，但未來若重新翻譯 Q&A 資料，仍可能再次出現。

3. **AI 翻譯一致性**：`どん ぴしゃり` 在不同 Q&A 條目被翻成 `Don Slap` 或 `Don Smack`，顯示 AI 翻譯不穩定。此 map 已涵蓋兩個變體，但若未來有更多 Q&A 使用其他翻譯，需再補充。

4. **掃描方式的侷限**：本次掃描透過比對 JP Q&A 文字中的 `「事件牌名」` marker 來識別受影響條目，對於 JP 文字本身牌名有誤（如 `じゃねぇぞ` vs `じゃねえぞ`）的情況，依靠 event card number 輔助搜索。如有更多牌名在 Q&A JP 文字中拼寫與 `all_cards.json` 不一致，可能有漏網之魚。
