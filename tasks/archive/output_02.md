## 評分公式（快速參照）

```
A = base_OP + 技能OP加成×可靠度 + 封殺等効値×可靠度
D = base_DP(rcv+blk) + 技能DP加成×可靠度
R = (抽牌×1.0 + 棄区回収×2.0 + 手牌回収×1.5) × 可靠度
S = 発動率 × 1.8^excess（excess = chain_OP - 6.0，≤0→S=0）
綜合 = 0.35A + 0.30D + 0.20R + 0.15S
```

## 評分細節備註（關鍵計算說明）

### HV-P02-016 宮 侑 頂（A=3.40 計算）
- base_OP = 1（tos=1）
- Guts3→tos+2：A加成 = 2×0.70 = 1.40
- どんぴしゃり條件→[ワンタッチ][レシーブフェイズ手札]スキル無効：封殺等効 2.5×0.40 = 1.00
- A = 1+1.40+1.00 = **3.40**
- R = 1.0×0.70 = 0.70（Guts3→引1）
- S = 0.40 × 1.8^4 = 0.40×10.50 = **4.20**（chain_OP=10，excess=4）

### HV-P02-020 宮 治 頂（A=5.10 計算）
- base_OP = 2（atk=2）
- Guts3→atk+3：A加成 = 3×0.70 = 2.10
- どんぴしゃり條件→atk+1(0.40)+ブロック人数制限1.5×0.40=0.60：合計 1.00
- A = 2+2.10+1.00 = **5.10**
- D = 4（rcv3+blk1）
- S = **4.20**（同上）

### HV-P02-087 どんぴしゃり（S=4.20 計算）
- chain_OP = 宮侑頂(tos1+2=3) + 宮治頂(atk2+3+1=6) + param+1 = **10**
- excess = 10 - 6.0 = 4
- S = 0.40 × 1.8^4 = **4.20**
- A = 1.20（稲荷崎キャラparam+1 全體加成，估3名×0.40可靠度）

## 牌組分析報告

### 1. 攻守比例

```
平均A值（每張）：
Characters: (3.40+5.10)×3 + (3.0×24卡位) + 4.0×2 / 32
≈ (10.2+15.3+72+8) / 32 = 105.5 / 32 ≈ 3.30

平均D值（每張）：
(0+4.0)×3 + (6.0+6.0+6.0+6.0+5.55+6.0+6.0+7.70)×3 + 0×2 / 32
= (0+12 + 49.25×3 + 0) / 32
≈ (12 + 147.75) / 32 ≈ 4.99

攻守比 A:D = 3.30 : 4.99 ≈ 0.66 → 防守略偏重
```

**判定：防守型進攻牌組（Defense-Forward Offense）**  
- 日常回合靠 DP=6 的多張卡防守對手進攻
- 鏈條回合（chain_OP=10）突破對手 DP，一舉拉分
