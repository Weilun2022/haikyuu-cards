## 【評分框架】

### 官方規則核心
- OP = tos + atk（技能加成後）→ OP > 對手 DP → 得分
- DP = rcv + blk（接球+攔網合計）
- 數值欄位顯示 `-` = 不具備此能力，不計入 OP/DP
- Event 牌上限 8 張，總牌數恰好 40 張
- 合計欄位 ≠ OP，不可混用

### 四維度評分
```
A 攻擊有效值（權重 0.35）
  = base_OP + 技能OP加成×可靠度 + 封殺等效值×可靠度

D 防守有效值（權重 0.30）
  = base_DP(rcv+blk) + 技能DP加成×可靠度

R 資源價值（權重 0.20）
  = (抽牌×1.0 + 棄區回收×2.0 + 手牌回收×1.5) × 可靠度

S 連動加成（權重 0.15）
  excess = chain_OP - 對手平均DP（預設 6.0）
  S = 發動率 × 1.8^excess（excess ≤ 0 → S = 0）

綜合貢獻分 = 0.35A + 0.30D + 0.20R + 0.15S
```

### 技能可靠度
```
無條件         = 1.00
Guts 1-2      = 0.85
Guts 3        = 0.70
Guts 4+       = 0.55
手牌 ≤ 3      = 0.65
棄牌 4 種     = 0.60
棄牌 6 種     = 0.45
依賴對手狀態  = 0.35
複合條件相乘
```

### 封殺等效值（納入 A）
```
スキルを無効       = +2.5
MB攔網歸零         = +3.0
ブロック人數限制   = +1.5
禁止打出攔網事件牌 = +1.5
禁止登場S舉球手    = +2.0
對手rcv -N（每點） = +0.8
```

### 稲荷崎核心連鎖
- どんぴしゃり 觸發條件：宮侑在tos區 + 宮治在atk區
- 連鎖後：Guts 的宮侑（頂）進tos區 + Guts 的宮治（頂）進atk區
- 最大連鎖 OP = 宮侑頂(tos 1+2=3) + 宮治頂(atk 2+3+1=6) = **9**（どんぴしゃり+1 → 10）
- 連鎖發動率估計：0.40（牌組含3張宮侑頂+宮治頂時）
