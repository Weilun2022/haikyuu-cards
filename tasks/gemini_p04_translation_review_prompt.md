# 什麼算「疑慮」（請標分類）

- **A 意思錯誤**：條件、對象、數量、時機、誰做動作等規則意義與日文不符（最嚴重，會影響遊戲判定）
- **B 漏譯／多譯**：日文有的內容沒譯出，或譯文多出日文沒有的內容
- **C 術語不一致**：用詞不符 `official_terms.json` 或既有 `MANUAL_OVERRIDES` 慣例
- **D 語序／可讀性**：意思對，但語序不自然、易誤讀，且有既有慣例可循
- **E 原文疑點**：你懷疑 `skill_jp` 本身轉錄有誤（第四彈原文是人工從 PDF 轉錄的），請對照卡面圖片說明
- **F 譯名**：`name_zh` 的人名用字或事件卡名翻譯有問題

只是換個說法、意思和慣例都沒錯的，**不要列**。
